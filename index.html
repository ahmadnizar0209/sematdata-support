Getting started

Import files or a folder, select media in the table, and inspect its metadata. Activate the 14-day trial or unlock SematData to edit fields and cover artwork. Review staged changes before saving. Changes do not reach the original files until you choose Save.

Supported formats

MP3, M4A, MP4, AAC, FLAC, WAV, AIFF, AIFC, OGG, Opus, and MOV. Available fields and artwork support depend on the container and file structure. Each workspace supports up to 1,000 media files. SematData requires macOS 14 or later.

Trial and one-time purchase

The trial provides 14 days of editing and saving from activation. When it ends, those features require a one-time unlock. Importing and inspecting files remain available. There is no subscription or automatic charge. The U.S. unlock price is $17.99; Apple displays the price in your local currency before purchase. Use SematData > Trial & Purchase > Restore Purchases with the same Apple Account to restore access. Restoring does not restart an expired trial.

Saving safely

SematData verifies the edited output before replacing the original file. It does not keep a backup copy. Keep a separate backup of important media before editing. macOS may ask you to select the containing folder to allow saving. If a file is locked, unsupported, or has changed externally, the app reports the problem rather than silently overwriting it.

Request help
